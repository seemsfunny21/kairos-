# Καιρός — PWA

Ελληνική εφαρμογή πρόγνωσης καιρού, με έμφαση στα Ιωάννινα και την ποδηλασία.

## Λειτουργίες

- Ζωντανή θερμοκρασία, αισθητή, υγρασία, άνεμος / ριπές, UV και πιθανότητα βροχής.
- Ωριαία πρόγνωση 12 ωρών, πρόγνωση 7 ημερών, ανατολή / δύση.
- Τρία καλύτερα δίωρα για ποδήλατο στις επόμενες 48 ώρες, από απλό **ενδεικτικό** score καιρικών συνθηκών, όχι πρόβλεψη ασφάλειας.
- Αναζήτηση πόλης στα ελληνικά ή προαιρετική επιλογή τοποθεσίας GPS.
- Αποθήκευση τελευταίας πρόγνωσης τοπικά, και offline PWA shell.
- Δεν απαιτεί Supabase, κωδικούς, λογαριασμούς ή πληρωμή για απλή προσωπική/μη εμπορική χρήση.

## Δεδομένα

[Open-Meteo](https://open-meteo.com/en/docs) Forecast API και [Geocoding API](https://open-meteo.com/en/docs/geocoding-api). Η πρόγνωση ανανεώνεται κατά το άνοιγμα αν είναι άνω των 15 λεπτών και όταν ζητηθεί χειροκίνητα. Η θέση αποθηκεύεται μόνο στο `localStorage` της συσκευής. Οι συντεταγμένες στέλνονται στο Open-Meteo για το αίτημα πρόγνωσης.

## Δημοσίευση σε αυτόνομο GitHub repository

1. Δημιούργησε **public** repository με όνομα `kairos` στο GitHub, με προαιρετικό αρχικό README.
2. Ανέβασε όλα τα αρχεία αυτού του φακέλου **στο root** του repository.
3. GitHub repository → Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.
4. Άνοιξε `https://seemsfunny21.github.io/kairos/` όταν δημοσιευτεί.

Η ίδια εφαρμογή μπορεί να λειτουργεί προσωρινά από `https://seemsfunny21.github.io/applications/kairos/` χωρίς αλλαγή αρχείων.

## Εγκατάσταση

Android: Chrome → εγκατάσταση εφαρμογής. iPhone: Safari → Κοινή χρήση → Προσθήκη στην οθόνη Αφετηρίας.

## Συντήρηση

Σε αλλαγές στα στατικά assets, αύξησε το `CACHE` στο `sw.js`. Δεν υπάρχει συνεχιζόμενη polling ή animation που να εκτελείται στο παρασκήνιο.
